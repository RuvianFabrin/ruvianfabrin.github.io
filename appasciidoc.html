Your ideas, in plain text

Write it once. Find it, shape it and share it with ease.

AppAsciiDoc is a lightweight desktop workspace for turning scattered notes into clear, connected documentation. Write in AsciiDoc, see the finished page as you type, and keep every file in folders you control.

Made for real knowledge work

Everything you need to keep documentation moving.

From the first outline to a polished export, AppAsciiDoc keeps writing, organizing and sharing in one focused place.

Write and preview together

Edit AsciiDoc with inline formatting, or switch to split view and preview. Headings, tables, links and code blocks take shape while you write.

Build a connected workspace

Keep notes in folders, link related pages, search across your workspace, revisit recent files, and explore backlinks and a local note graph.

Sync when you choose

Git stays optional. Opening a folder does not create a repository. Configure a remote, review local and remote changes, then start sync with a click. Conflicting versions are preserved for review.

Protect notes with AGE

Encrypt a note with a passphrase and keep its interoperable .age file for Git sync. Decrypt it on another AppAsciiDoc device with the same passphrase.

Share polished output

Export notes as HTML, PDF or a static site. Use the same source for internal procedures, public guides and project documentation.

Work in your language

The interface is available in Brazilian Portuguese, English, Spanish and Simplified Chinese.

Light by design

Your files stay yours. The app stays out of the way.

AppAsciiDoc works with local folders and does not require an account or cloud service. The current Windows NSIS installer is about 4.5 MB. Memory usage has not yet been measured.

Desktop compatibility

Windows

64-bit Windows 10 version 1803 or later, and Windows 11. Requires Microsoft Edge WebView2 Runtime.

Linux

64-bit distributions with GTK 3 and WebKitGTK 4.1. Ubuntu 22.04+ and Debian 12+ are reference baselines.

macOS

macOS Catalina 10.15 or later. The configured universal build targets Intel and Apple Silicon.

These minimums follow the project configuration and Tauri requirements. The CI workflow builds for all three desktop systems; testing on every minimum-version device is still in progress. Linux AppImage users need the GTK 3 and WebKitGTK 4.1 runtime libraries.

Frequently asked questions

Can I use AppAsciiDoc without Git or a cloud account?

Yes. AppAsciiDoc opens local folders and works without an account or cloud service. Git synchronization is optional and starts only after you configure a remote and click sync.

How does AGE encryption work?

Encrypt a note with a passphrase to create an interoperable .age file. The same passphrase can decrypt it on another AppAsciiDoc device.
