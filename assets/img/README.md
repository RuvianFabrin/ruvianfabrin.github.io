# Imagens do site

Coloque os screenshots com estes nomes EXATOS nesta pasta — o HTML já
referencia esses caminhos, então a imagem aparece sozinha assim que o
arquivo existir aqui, sem precisar editar nada.

| Arquivo | Onde aparece | Sugestão de conteúdo |
|---|---|---|
| `cerne-hero.png` | `index.html`, card do projeto | Tela principal do Cerne Code (chat + composer) |
| `cerne-main.png` | `cerne-code.html`, topo | Tela principal do Cerne Code (chat + composer + sidebar) |
| `cerne-skills-panel.png` | `cerne-code.html`, seção de skills | Painel "Agentes & Skills" aberto |
| `cerne-diff-viewer.png` | `cerne-code.html`, seção de skills | Visualizador de diff do repositório |

Formato recomendado: PNG ou JPG, proporção próxima de 16:10 (a caixa já
corta/centraliza automaticamente via `background-size: cover`). Pode
apagar este README depois.
