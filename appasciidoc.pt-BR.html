Feito para organizar conhecimento

Ferramentas para a documentação continuar avançando.

Do primeiro esboço à publicação, escreva, organize e compartilhe sem sair do mesmo lugar.

Edite e veja o resultado

Escreva em AsciiDoc com formatação inline ou use o modo dividido e a pré-visualização. Títulos, tabelas, links e blocos de código ganham forma durante a escrita.

Conecte suas notas

Organize arquivos em pastas, ligue páginas relacionadas, pesquise no workspace e consulte referências, arquivos recentes e o grafo local de notas.

Sincronize quando quiser

O Git é opcional. Abrir uma pasta não cria um repositório. Configure um remoto, confira diferenças locais e remotas e inicie a sincronização com um clique. Versões em conflito são preservadas para análise.

Proteja notas com AGE

Criptografe uma nota com senha e mantenha o arquivo .age compatível com sincronização Git. Descriptografe em outro dispositivo AppAsciiDoc com a mesma senha.

Publique em vários formatos

Exporte como HTML, PDF ou site estático. Use o mesmo conteúdo em procedimentos internos, guias públicos e documentação de projetos.

Use no seu idioma

A interface está disponível em português do Brasil, inglês, espanhol e chinês simplificado.

Leve por escolha

Seus arquivos continuam seus. O app não atrapalha.

O AppAsciiDoc trabalha com pastas locais e não exige conta nem serviço de nuvem. O instalador NSIS atual para Windows tem cerca de 4,5 MB. O uso de memória ainda não foi medido.

Compatibilidade desktop

Windows

Windows 10 64 bits, versão 1803 ou posterior, e Windows 11. Requer Microsoft Edge WebView2 Runtime.

Linux

Distribuições 64 bits com GTK 3 e WebKitGTK 4.1. Ubuntu 22.04+ e Debian 12+ são as referências mínimas.

macOS

macOS Catalina 10.15 ou posterior. O build universal configurado atende Macs Intel e Apple Silicon.

As versões mínimas seguem a configuração do projeto e os requisitos do Tauri. O CI compila para os três sistemas; ainda faltam testes em máquinas com cada versão mínima. No Linux, o AppImage precisa das bibliotecas de runtime GTK 3 e WebKitGTK 4.1.

Perguntas frequentes

Posso usar o AppAsciiDoc sem Git ou conta na nuvem?

Sim. O AppAsciiDoc abre pastas locais e funciona sem conta ou serviço de nuvem. A sincronização Git é opcional: configure um remoto e clique em sincronizar para começar.

Como funciona a criptografia AGE?

Criptografe uma nota com uma senha para criar um arquivo .age compatível com outras ferramentas AGE. A mesma senha permite descriptografar em outro dispositivo AppAsciiDoc.
