Para organizar conocimiento útil

Todo lo necesario para avanzar con tu documentación.

Desde el primer borrador hasta la publicación, escribe, organiza y comparte en un mismo lugar.

Edita y previsualiza a la vez

Escribe en AsciiDoc con formato integrado o usa la vista dividida y la previsualización. Los títulos, tablas, enlaces y bloques de código toman forma mientras escribes.

Conecta tus notas

Organiza archivos en carpetas, enlaza páginas relacionadas, busca en todo el workspace y consulta referencias, archivos recientes y el grafo local.

Sincroniza cuando tú quieras

Git es opcional. Abrir una carpeta no crea un repositorio. Configura un remoto, revisa las diferencias locales y remotas e inicia la sincronización con un clic. Las versiones en conflicto se conservan para revisarlas.

Protege notas con AGE

Cifra una nota con una contraseña y conserva el archivo .age para sincronizarlo con Git. Descífralo en otro dispositivo AppAsciiDoc con la misma contraseña.

Comparte en varios formatos

Exporta como HTML, PDF o sitio estático. Aprovecha el mismo contenido para procedimientos internos, guías públicas y documentación de proyectos.

Trabaja en tu idioma

La interfaz está disponible en portugués de Brasil, inglés, español y chino simplificado.

Ligero por diseño

Tus archivos siguen siendo tuyos. La app no estorba.

AppAsciiDoc trabaja con carpetas locales y no requiere cuenta ni servicios en la nube. El instalador NSIS actual para Windows ocupa unos 4,5 MB. El uso de memoria aún no se ha medido.

Compatibilidad de escritorio

Windows

Windows 10 de 64 bits, versión 1803 o posterior, y Windows 11. Requiere Microsoft Edge WebView2 Runtime.

Linux

Distribuciones de 64 bits con GTK 3 y WebKitGTK 4.1. Ubuntu 22.04+ y Debian 12+ son las referencias mínimas.

macOS

macOS Catalina 10.15 o posterior. La compilación universal configurada cubre Intel y Apple Silicon.

Las versiones mínimas se basan en la configuración del proyecto y los requisitos de Tauri. CI compila para los tres sistemas; aún faltan pruebas en equipos con cada versión mínima. En Linux, AppImage necesita las bibliotecas GTK 3 y WebKitGTK 4.1.

Preguntas frecuentes

¿Puedo usar AppAsciiDoc sin Git ni una cuenta en la nube?

Sí. AppAsciiDoc abre carpetas locales y funciona sin cuenta ni servicio en la nube. Git es opcional: configura un remoto y pulsa sincronizar para empezar.

¿Cómo funciona el cifrado AGE?

Cifra una nota con una contraseña para crear un archivo .age compatible con otras herramientas AGE. La misma contraseña permite descifrarlo en otro dispositivo AppAsciiDoc.
