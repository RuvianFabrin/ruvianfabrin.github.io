AppAsciiDoc 是一款轻量级桌面工作区，帮助你把零散笔记整理成清晰、相互关联的文档。使用 AsciiDoc 写作，编辑时即可查看预览，并将文件保存在自己管理的文件夹中。

为知识整理而设计

让文档创作持续推进所需的工具。

从初稿到成品，在同一个专注的空间中写作、整理并分享。

边写边预览

使用 AsciiDoc 和行内格式编写，也可以切换到分栏视图与预览。标题、表格、链接和代码块会随写作逐步呈现。

连接相关笔记

将笔记放入文件夹、链接相关页面、搜索整个工作区，并查看反向链接、最近文件和本地笔记关系图。

由你决定何时同步

Git 是可选功能。打开文件夹不会自动创建仓库。配置远程仓库后，可先查看本地与远程差异，再点击开始同步。冲突版本会保留下来供你检查。

使用 AGE 保护笔记

用密码加密笔记，并保留可通过 Git 同步的 .age 文件。在另一台 AppAsciiDoc 设备上使用同一密码即可解密。

导出并分享

将文档导出为 HTML、PDF 或静态网站。同一份内容可用于内部流程、公开指南和项目文档。

使用熟悉的语言

界面支持巴西葡萄牙语、英语、西班牙语和简体中文。

一个工具，多种写作场景

让有用的信息井然有序。

AsciiDoc 适合撰写长篇、结构化内容。AppAsciiDoc 则让这些文档集中保存，并且易于搜索。

轻巧而专注

文件由你掌控，应用不会喧宾夺主。

AppAsciiDoc 使用本地文件夹，无需账号或云服务。当前 Windows NSIS 安装包约为 4.5 MB。内存占用尚未测量。

桌面系统兼容性

Windows

64 位 Windows 10 版本 1803 或更高版本，以及 Windows 11。需要 Microsoft Edge WebView2 Runtime。

Linux

64 位系统，支持 GTK 3 和 WebKitGTK 4.1。Ubuntu 22.04+ 与 Debian 12+ 是参考基线。

macOS

macOS Catalina 10.15 或更高版本。当前通用构建支持 Intel 与 Apple Silicon Mac。

最低版本依据项目配置和 Tauri 要求。CI 会为三种桌面系统构建；仍需在每个最低版本的实际设备上测试。Linux AppImage 需要 GTK 3 和 WebKitGTK 4.1 运行库。

常见问题

不使用 Git 或云账户也能使用 AppAsciiDoc 吗？

可以。AppAsciiDoc 可打开本地文件夹，无需账户或云服务。Git 同步是可选的；配置远程仓库并点击同步后才会开始。

AGE 加密如何工作？

使用密码加密笔记后会生成兼容 AGE 工具的 .age 文件。可在另一台 AppAsciiDoc 设备上使用相同密码解密。
