Um agente de código que roda no seu computador.

Cerne Code lê, edita e cria arquivos de verdade, roda comandos, gera documentos, pesquisa na web e pode até controlar a tela — tudo local, com a opção de um modelo 100% local (nada sai da sua máquina) ou um provider de API à sua escolha.

O que é

O mesmo agente de linha de comando, numa janela de verdade.

Cerne Code é um app desktop nativo pra Windows, construído com Tauri v2 (backend em Rust) e Vue 3 no frontend. A ideia é dar pra qualquer pessoa a mesma experiência de um agente de codificação por linha de comando — só que com histórico de sessões, visualização de diff, anexos e tudo mais que uma interface gráfica permite que um terminal não dá de graça.

É local-first por decisão de design: o app roda inteiramente no seu computador, e você escolhe se o modelo por trás também roda localmente (llama.cpp, Ollama, LM Studio) ou se prefere um provider de API. Os dois caminhos recebem o mesmo cuidado.

Providers

Quatro formas de conectar um modelo.

Todos falam o mesmo protocolo — trocar de um pro outro é só trocar a seleção.

OpenRouter

Dezenas de modelos de API (Claude, GPT, Gemini) por uma única chave.

llama.cpp local

Múltiplos "forks" configuráveis — o app sobe e derruba o servidor sozinho.

Ollama & LM Studio

Os dois runtimes locais mais usados, com detecção automática de modelos.

Provider customizado

Qualquer endpoint compatível com a API de chat completions da OpenAI.

Ferramentas

Tudo que um agente de código precisa pra ser útil de verdade.

O modelo decide sozinho, turno a turno, qual ferramenta usar — com base no que você pediu.

Ler, editar e criar arquivos

Edições passam por uma sandbox com diff — você revisa e aceita antes de qualquer coisa tocar o arquivo real.

Busca e edição estrutural

ast_grep/ast_edit casam pela forma da árvore sintática, não texto solto.

Rodar comandos

Testes, build, lint, git — inclusive dev servers em segundo plano, com aviso automático quando terminam.

Pesquisar na web

Busca multi-motor sem conta nem chave por padrão, com opção de Brave, Tavily ou SearXNG próprio.

Gerar documentos

Excel, Word, PDF e PowerPoint — com tabelas, imagens e formatação, escritos direto no disco.

Controlar a tela

Screenshot, clique, digitação e atalhos em outras aplicações, quando a tarefa pede automação.

Servidores MCP

Qualquer servidor Model Context Protocol configurado vira ferramenta disponível pro agente.

Criar suas próprias ferramentas

O agente escreve um script Python e registra como ferramenta reutilizável via uv.

Orquestração

Um agente que sabe delegar.

Além de responder direto, o agente principal pode espalhar trabalho por outros agentes.

Sub-agentes

Delega uma sub-tarefa bem definida pra um agente descartável, que devolve só o relatório final.

Verificador adversarial

Antes de declarar sucesso, um verificador cético confirma com evidência real — não só lendo código.

Pipeline Dev → QA → Analista

Implementa, confirma que funciona, confirma que atende o pedido — voltando pro início se algo não bater.

Execução paralela

Sub-tarefas independentes rodam ao mesmo tempo quando o provider é de API.

Personalização

Ensine comportamento sem escrever código.

Skills

Um arquivo de instruções que o agente carrega sozinho quando decide que é relevante. Dá pra criar as suas, ou importar de uma URL.

Personas

Um "modo" que vale a sessão inteira — um tutor de inglês, um revisor sênior — com allowlist opcional de ferramentas.

Controle de execução

Manual (aprova cada ação), Automático (roda direto, cancelável) ou YOLO (edição direta, sem sandbox).

Multi-idioma

Interface completa em português, inglês, espanhol e chinês.
