Cerne Code

Um agente de código local com interface gráfica — o equivalente ao Claude Code em formato de app desktop nativo. Lê, edita e cria arquivos de verdade no seu computador, roda comandos, gera documentos, pesquisa na web e pode até controlar a tela — tudo isso rodando local, com a opção de usar um modelo 100% local (sem nada saindo da sua máquina) ou um provider de API à sua escolha.

O que é

Cerne Code é um app desktop nativo (Windows) construído com Tauri v2 (backend em Rust) e Vue 3 + PrimeVue no frontend. A ideia central é dar pra qualquer pessoa a mesma experiência de um agente de codificação por linha de comando — só que numa janela de verdade, com histórico de sessões, visualização de diff, anexos, e tudo mais que uma interface gráfica permite que um terminal não dá de graça.

É local-first por decisão de design: o app em si roda inteiramente no seu computador, e você escolhe se o modelo de linguagem por trás também roda localmente (via llama.cpp, Ollama ou LM Studio) ou se prefere usar um provider de API. Os dois caminhos recebem o mesmo cuidado — não é "modo local incompleto".

Providers suportados

OpenRouter

Acesso a dezenas de modelos de API (Claude, GPT, Gemini, e por aí vai) por uma única chave.

llama.cpp local

Múltiplos "forks" configuráveis, cada um na sua porta — o app sobe e derruba o servidor sozinho conforme a sessão precisa.

Ollama & LM Studio

Os dois runtimes locais mais usados, com detecção automática de modelos instalados.

Provider customizado

Qualquer endpoint compatível com a API de chat completions da OpenAI — sem travar em nomes de marca específicos.

O que o agente sabe fazer

Tudo abaixo é decidido pelo próprio modelo, turno a turno — ele escolhe qual ferramenta usar (ou nenhuma) com base no que você pediu.

Ler, editar e criar arquivos

Edições passam por uma sandbox com diff — você revisa e aceita antes de qualquer coisa tocar o arquivo real (ou aceita rodar sem essa pausa, no modo mais rápido).

Busca e edição estrutural

ast_grep/ast_edit casam pela forma da árvore sintática do código, não por texto solto — refactors mais seguros que um find-and-replace.

Rodar comandos

Testes, build, lint, git — inclusive processos de longa duração (dev server) em segundo plano, com o resultado aparecendo sozinho no histórico quando termina.

Pesquisar na web

Busca multi-motor sem precisar de conta nem chave por padrão, com opção de Brave, Tavily ou SearXNG próprio.

Gerar documentos

Planilhas Excel, documentos Word, PDFs e apresentações PowerPoint — com tabelas, imagens e formatação, escritos direto no disco.

Controlar a tela

Screenshot, clique, digitação e atalhos de teclado em outras aplicações, quando a tarefa pede automação fora do próprio código.

Servidores MCP

Qualquer servidor Model Context Protocol que você configurar vira ferramenta disponível pro agente automaticamente.

Criar suas próprias ferramentas

O agente pode escrever um script Python e registrá-lo como ferramenta reutilizável, com dependências gerenciadas via uv — sem você precisar programar nada.

Orquestração de agentes

Além de responder diretamente, o agente principal pode delegar trabalho:

  • Sub-agentes — delega uma sub-tarefa bem definida pra um agente descartável, que devolve só o relatório final, sem poluir a conversa com os passos intermediários.
  • Verificador adversarial — antes de declarar sucesso numa tarefa complexa, um verificador cético e independente confirma com evidência real (rodando teste/build de verdade, não só lendo código).
  • Pipeline Dev → QA → Analista — pra tarefas que merecem o rigor completo: um implementa, outro confirma que funciona tecnicamente, um terceiro confirma que atende o que foi pedido — voltando pro início automaticamente se algo não bater, em rounds controlados.
  • Execução paralela — múltiplas sub-tarefas independentes rodam ao mesmo tempo quando o provider é de API.

Skills e Personas

Duas formas de ensinar comportamento ao agente sem escrever código:

  • Skills — um arquivo de instruções que o agente carrega sozinho quando decide que é relevante pro pedido atual (ex: "como organizar uma pasta de downloads", "como triar e-mails"). Dá pra criar as suas, ou importar de uma URL.
  • Personas — um "modo" que vale a sessão inteira, escolhido por você (ex: um tutor de inglês, um revisor de código sênior), com uma lista opcional de ferramentas/skills que essa persona pode usar.

Controle e segurança

Três modos de execução, escolhidos por sessão: Manual (toda ação pausa pedindo aprovação), Automático (roda direto, com um botão de cancelar sempre à mão) e YOLO (edição direta no arquivo real, sem sandbox, pra quem já confia no fluxo e quer velocidade máxima).

Multi-idioma

Interface completa em português, inglês, espanhol e chinês.
