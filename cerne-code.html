Overview

The same coding agent power, in a real GUI.

Built with Tauri v2 (Rust backend) and Vue 3 on the frontend. Cerne Code brings the agent experience to a native window — with session history, inline diff review, file attachments, and everything a terminal can't give you for free.

It's local-first by design: the app runs entirely on your computer. You choose whether the model runs locally too (llama.cpp, Ollama, LM Studio) or through an API provider. Both paths get the same care.

Providers

Four ways to connect a model.

All speak the same protocol — switching is one click.

OpenRouter

Dozens of API models (Claude, GPT, Gemini) through a single key.

llama.cpp local

Multiple configurable "forks" — the app starts and stops the server automatically.

Ollama & LM Studio

The two most popular local runtimes, with automatic model detection.

Custom provider

Any OpenAI-compatible endpoint — Claude, Grok, Qwen, Kimi, and more.

Tools

Everything a coding agent needs to be truly useful.

The model decides, turn by turn, which tool to use — based on what you asked.

Read, edit & create files

Edits go through a sandbox with diff review — you approve before anything touches the real file.

Structural code search

ast_grep/ast_edit match by AST shape, not loose text. 28 languages supported.

Run commands

Tests, build, lint, git — including background dev servers with automatic notification when done.

Web search

Multi-engine search (DuckDuckGo + Brave + Mojeek) with no account or key by default. Optionally Brave API, Tavily, or your own SearXNG.

Create documents

Excel, Word, PDF, PowerPoint — with tables, images, and formatting, written directly to disk.

Screen control

Screenshot, click, type, and keyboard shortcuts in other applications when the task needs automation.

MCP servers

Any Model Context Protocol server you configure becomes a tool available to the agent. Connection test before saving.

Create your own tools

The agent writes a Python script and registers it as a reusable tool via uv — available in every future session.

Git integration

Reads your project's git history, remembers preferences across sessions, and checks dependency vulnerabilities via OSV.

Background execution

Long-running commands (dev server, build) don't block the chat. The agent automatically reacts when they finish.

一个生活在您电脑上的代码助手。

Cerne Code 是一款原生桌面应用，能将任何语言模型转变为真正的代码助手。 编辑文件、运行命令、搜索网页、创建文档、控制屏幕 — 全部本地运行，完全免费，不计 token。

主界面 — 与助手聊天、编辑器、会话侧边栏
概述

同样的代码助手能力，在一个真正的图形界面中。

使用 Tauri v2（Rust 后端）和 Vue 3 前端构建。 Cerne Code 将代码助手的体验带入原生窗口 — 具备会话历史、内联差异审查、 文件附件以及终端无法免费提供的一切。

它天生是 本地优先 的：应用完全在您的计算机上运行。您可以选择 模型是否也在本地运行（llama.cpp、Ollama、LM Studio），或者通过 API 提供商。 两种方式都得到同样的精心照顾。

提供商

四种连接模型的方式。

都使用相同的协议 — 一键切换。

OpenRouter

通过单一密钥访问数十种 API 模型（Claude、GPT、Gemini）。

本地 llama.cpp

多个可配置的 "分支" — 应用自动启动和停止服务器。

Ollama & LM Studio

最流行的两种本地运行时，具有自动模型检测功能。

自定义提供商

任何兼容 OpenAI 的端点 — Claude、Grok、Qwen、Kimi 等。

工具

代码助手真正有用所需的一切。

模型根据您的请求，逐轮决定使用哪个工具。

读取、编辑和创建文件

编辑通过沙箱和差异审查 — 在触及真实文件之前，您可以批准每一项更改。

结构化代码搜索

ast_grep/ast_edit 按 AST 形状匹配，而非松散文本。支持 28 种语言。

运行命令

测试、构建、代码检查、Git — 包括后台开发服务器，完成时自动通知。

网页搜索

多引擎搜索（DuckDuckGo + Brave + Mojeek），默认无需账户或密钥。可选 Brave API、Tavily 或自建 SearXNG。

创建文档

Excel、Word、PDF、PowerPoint — 带表格、图片和格式，直接写入磁盘。

屏幕控制

截图、点击、输入和快捷键操作其他应用程序，当任务需要自动化时。

MCP 服务器

任何配置的 MCP 服务器都会成为助手的可用工具。保存前可测试连接。

创建自己的工具

助手编写 Python 脚本并通过 uv 注册为可复用工具 — 在未来的所有会话中可用。

Git 集成

读取项目的 Git 历史、跨会话记住偏好、并通过 OSV 检查依赖项漏洞。

后台执行

长时间运行的命令（开发服务器、构建）不会阻塞对话。助手在完成后自动响应。
