Projeto em destaque

Desktop · Tauri + Rust + Vue

Cerne Code

Um agente de código local com interface gráfica — pense num "Claude Code" em formato de app desktop. Lê, edita e cria arquivos de verdade, roda comandos, gera documentos (Excel/Word/PDF/PowerPoint), pesquisa na web, controla a tela quando precisa, e se conecta a modelos locais (llama.cpp, Ollama, LM Studio) ou de API (OpenRouter e qualquer provider compatível com OpenAI).
