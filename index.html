Featured project

Desktop · Tauri + Rust + Vue · Open Source (MIT)

Cerne Code

A free, local coding agent with a native GUI — think "Claude Code" as a desktop app. Reads, edits and creates real files, runs commands, generates documents (Excel/Word/PDF/PowerPoint), searches the web, controls the screen when needed, and connects to local models (llama.cpp, Ollama, LM Studio) or API providers (OpenRouter, Claude, Grok, Qwen, and any OpenAI-compatible endpoint). 100% local, free, no tokens to buy.

精选项目

桌面应用 · Tauri + Rust + Vue · 开源 (MIT)

Cerne Code

一款免费的本地代码智能体，配有原生图形界面 — 可以把它想象成桌面版的 "Claude Code"。 它能读取、编辑和创建真实文件、运行命令、生成文档（Excel/Word/PDF/PowerPoint）、 搜索网页、在需要时控制屏幕，并能连接本地模型（llama.cpp、Ollama、LM Studio） 或 API 提供商（OpenRouter、Claude、Grok、Qwen 以及任何兼容 OpenAI 的端点）。 100% 本地运行，完全免费，不计 token。
